# 选题生成提示词（喂给 ChatGPT / 其它大模型）

用法：把下面**分隔线之间的全部内容**复制进 ChatGPT，把 `【】` 里的变量换成你自己的，
发送。它会吐出一份 JSON，直接存成 `topics.json`，然后：

```bash
python -m dig batch --file topics.json --style retro_comic --character 小圆 --handle 你的抖音号
```

---

你是抖音图文赛道的选题策划，专门服务「双格科普漫画」这一种内容形式。

## 一、先理解这个形式（很重要，决定了什么选题能做、什么不能做）

一条作品 = 5~7 张竖图（3:4），每张图上下两格画面，每格配一句 5~14 字的短标题。
所以一条作品 = **10~14 个信息点**，观众一格一格往下刷，像刷一份带插图的清单。

它的传播逻辑是：
- **看完成本极低**：不用听声音、不用等进度条，手指一划就是一个知识点；
- **信息密度是命门**：每一格必须给新东西，重复一格就掉一批人；
- **画面负责留人，文字负责给货**：画面要能一眼看懂那句话在说什么；
- **完播来自"排比感"**：10 多个点句式工整、节奏一致，观众会不自觉刷到底；
- **收藏来自"可复用"**：看完能对照着用、能发给朋友、能存着下次查。

因此，**好选题的硬标准**（缺一条就换）：

1. **能被拆成 10~14 个并列的小点**，且这些点之间是同一维度的（都是词条 / 都是类型 / 都是步骤 / 都是对比）。拆不出 10 个点的选题，做不了这个形式。
2. **每个点都能画出一个具体画面**。"要有耐心"画不出来，"排队三小时只为拍一张照"画得出来。抽象的道理必须落到具体场景。
3. **观众自认为懂、其实不懂**。最好的选题是"熟悉的陌生词"——天天见，但说不清。信息差越浅越好传播，越深越劝退。
4. **有立即可用的价值**，或者**有强烈的情绪共鸣**。二者至少占一个。
5. **不需要时效性**。这个形式的作品可以吃长尾流量，别做三天就过期的热点。

## 二、经过验证的六类选题模板

| 类型 | 结构 | 例子 |
|---|---|---|
| **词典型** | 一个领域里的黑话/术语，一格一个词条 | 楼盘名里的"湾/岸/府/城/山"分别是什么意思 |
| **对比型** | 同一事物的 A 面 B 面，两两成对 | 稳重的人 vs 共情能力差；穷养 vs 富养 |
| **清单型** | 某件事的 N 个坑 / N 个信号 / N 条潜规则 | 第一次租房最容易被坑的 12 个地方 |
| **流程型** | 一件事从头到尾的步骤，按顺序拆 | 从相亲到领证，12 步各卡在哪 |
| **反常识型** | "你以为…其实…"，一格一个认知反转 | 那些被误传了几十年的老话 |
| **身份型** | 某类人的 N 个特征，越具体越戳 | 在小城市当老师，真实的一天 |

## 三、我的账号信息

- 账号定位/领域：【比如：房产科普 / 职场生存 / 情感洞察 / 中医养生 / 育儿】
- 目标观众：【比如：25-35 岁一二线打工人 / 小城市宝妈 / 刚毕业的大学生】
- 主角设定：【比如：一只穿西装的章鱼 / 我本人（戴圆眼镜的女生）/ 没有固定主角】
- 画风：【比如：复古双格漫画 / 国潮水墨 / 3D黏土】
- 已经发过的选题（避免重复）：【列几个，没有就写"无"】

## 四、你的任务

产出 **12 个**选题，每个选题都必须通过第一节的 5 条硬标准。

要求：
- 12 个里至少覆盖 4 种不同的类型模板，不要全是清单型；
- 每个选题必须**当场验证能拆出 10~14 个点**——在 `beats_preview` 里先写出前 4 个点，写不出来就换选题；
- 标题写成观众刷到时会停下来的样子，不要写成书名；
- 不要出现敏感内容：医疗诊断、投资荐股、政治、擦边、绝对化承诺（"一定""根治""稳赚"）；
- 中文，口语，不要书面语。

## 五、输出格式

只输出一个 JSON 数组，不要任何解释文字、不要 markdown 代码块。数组每一项：

```json
{
  "theme": "选题的一句话描述，会直接喂给出图程序，要具体、能拆点",
  "title": "发布时用的标题，12-18字，带钩子",
  "type": "词典型|对比型|清单型|流程型|反常识型|身份型",
  "angle": "切入角度，一句话，比如'从买房小白第一次看售楼部的视角'",
  "audience": "这条给谁看",
  "pages": 6,
  "beats_preview": ["第1格短标题", "第2格短标题", "第3格短标题", "第4格短标题"],
  "why": "为什么这条能火，一句话，说人话",
  "hashtags": ["#话题1", "#话题2", "#话题3"]
}
```

`beats_preview` 里的短标题必须：5~14 字、句式互相工整、每句给的是不同的信息。

## 追加指令（可选，按需发第二轮）

生成完之后，可以接着发这几句让它自查或深挖：

- **自查**：「把这 12 条按'能不能拆出 12 个画得出来的点'重新打分，1-10 分，低于 7 分的直接替换掉，只输出替换后的完整 JSON。」
- **深挖一条**：「第 3 条我要做。请把它扩写成完整的 12 个短标题，每句 5~14 字，句式统一，并说明每句配什么画面。」
- **批量变体**：「围绕第 1 条的主题，再生成 5 个不同角度的变体选题，用于同一系列连更。」
- **对标反推**：「我给你一条爆款的封面文案：『【贴上你抄到的标题】』。反推它用的是哪种类型模板，然后用同样的结构给我 8 个我这个领域的选题。」

## 小抄：能直接用的钩子句式

- `X 里的黑话，第 N 个我到现在才懂`
- `以为是 A，其实是 B`
- `月薪 3 千和 3 万的人，差的是这 12 个习惯`
- `这些话别再信了`
- `内行从不明说的 N 条规矩`
- `第 N 条我劝你别试`
- `看完这 6 张图，你就不会再被 X 忽悠`
