# 选题生成提示词（喂给 ChatGPT / 其它大模型）

用法：把下面**分隔线之间的全部内容**复制进 ChatGPT，把 `【】` 里的变量换成你自己的，
发送。它会吐出一份 JSON，直接存成 `topics.json`，然后：

```bash
python -m dig batch --file topics.json --style retro_comic --character 小圆
```

每条选题的 `source`（取材出处）会一路带进写脚本的提示词，脚本会按那本书的原意来写。
让 Agent 自己写脚本时，也从第四节的取材库里挑观点，写进 script.json 的 `source`。

---

你是抖音图文赛道的选题策划，专门服务「双格科普漫画」这一种内容形式。
这个账号只做一件事：**让人看完就能照着做**。每条作品都要让观众刷完觉得"学到了，下次就这么办"。

## 一、先理解这个形式（很重要，决定了什么选题能做、什么不能做）

一条作品 = 5~7 张竖图（3:4），每张图上下两格画面，每格配一句 5~14 字的短标题。
所以一条作品 = **10~14 条做法**，观众一格一格往下刷，像刷一份带插图的操作清单。

它的传播逻辑是：
- **看完成本极低**：不用听声音、不用等进度条，手指一划就是一条做法；
- **"学到了"是命门**：每一格必须给一条新的、具体的做法，空话一格就掉一批人；
- **画面负责留人，文字负责给货**：画面演出主角正在照做，一眼看懂那句话；
- **完播来自"排比感"**：10 多条做法句式工整、节奏一致，观众会不自觉刷到底；
- **收藏来自"能照做"**：看完能对照着用、能发给朋友、能存着下次查。

## 二、好选题的硬标准（缺一条就换）

1. **能拆成 10~14 条并列的做法**，每条都是观众今天就能做的动作。拆不出 10 条具体做法的选题，做不了这个形式。
2. **每条做法都能画成一个动作**。"要有耐心"画不出来，"等一晚再回消息"画得出来。道理必须落到具体场景和动作。
3. **有出处、有分量**：优先从第四节的取材库里挑一个具体观点，把它翻成今天的场景。观众会因为"原来芒格/王阳明是这么说的"而信你、收藏你。
4. **天天用得上**：落在上班、人际、花钱、作息、学习、做决定这些每天都会遇到的事上。
5. **不需要时效性**。这个形式的作品吃长尾流量，别做三天就过期的热点。

## 三、六种能教会人的结构

| 类型 | 结构 | 例子 |
|---|---|---|
| **规则型** | 一位大家、一本书的 N 条规矩，一格一条 | 芒格的反向思考：想过好日子，先避开这几件事 |
| **阶段型** | 按阶段或时间顺序，每个阶段该做什么、别做什么 | 乾卦六条龙：职场每一步怎么走 |
| **步骤型** | 做成一件事的先后步骤，照着走就能完成 | 用"知行合一"戒掉拖延的 6 步 |
| **对照型** | 同一张图一格"别这样"、一格"要这样" | 叔本华：想过得好，先少受罪 |
| **场景应对型** | 遇到 X 就做 Y，一格一个场景 | 心乱、犯懒、想发火时，王阳明各给了一招 |
| **老话新用型** | 一格一句老话，冒号后面紧跟今天怎么做 | 10 句老话，句句能照着做 |

短标题一律用祈使句，全套句式统一。常用的几种：
- `先X` / `别X` / `X前先Y` / `遇到X就Y` / `把X换成Y`
- `阶段：做Y`（潜龙期：闷头练本事）
- `老话：做Y`（量体裁衣：先算再花）

## 四、取材库

下面每本书只列**能直接变成做法**的观点，都是转述，不是原文。选题时：
挑一个具体观点 → 想清楚它在今天的什么场景里用得上 → 拆成 10~14 条动作。
**不要编造书里的原话，不要虚构章节**；引用古文，后面必须紧跟一句大白话的做法。

### 1.《穷查理宝典》查理·芒格

- **反过来想**：想做成一件事，先列出会让它失败的做法，再一条条避开。
- **痛苦药方**（第一讲，哈佛学校毕业演讲）：芒格列过"保证过上痛苦生活"的做法——靠酒精之类的东西改变心情、妒忌、怨恨、说话不算数、只从自己的经历里学、摔一次就一蹶不振、死守年轻时的观点不改。反过来，就是一份规矩清单。
- **能力圈**：只在自己真懂的范围里下判断，圈外的事直接说"不懂"。
- **检查清单**：重要决定前过一遍清单，好飞行员从不跳过。
- **配得上**：想得到什么（工作、伴侣、信任），先让自己配得上它。
- **发表观点的资格**：能比对手更好地驳倒自己的立场，才有资格开口。
- **先看激励**：想知道一个人会怎么做，先看他靠什么拿好处；别待在"越糊弄越有好处"的环境里。
- **从别人的坑里学**：大多数灾难都没什么新意，别亲自再踩一遍。
- **每天比昨天聪明一点**：慢慢变好，不求一步登天；每天读书。
- **误判心理**（第十一讲）：随大流、怕失去、迷信权威、对比错觉、压力下乱判断……每一种都能写成一条"遇到这种情况，先停一下"。

适合：规则型、场景应对型、对照型。
例：`芒格的反向思考：先避开这几件事` → 别妒忌跑得快的人 / 别记仇 / 说到就要做到 / 摔倒马上爬起来 / 从别人的坑里学……

### 2.《人生的智慧》叔本华

- **三笔账按顺序算**：你是什么样的人（健康、性情、头脑）＞你拥有什么＞别人怎么看你。先顾好第一笔。
- **健康排第一**：不拿健康去换钱、换名声、换一时痛快。
- **不求快乐，先求少受罪**：日子过得好不好，看烦心事少不少，不看高兴事多不多。
- **把欲望和圈子缩小**：想要的越少、来往的圈子越窄，烦恼越少。
- **少在意别人的看法**：别人的评价是最靠不住的幸福来源。
- **想要新东西时**：先想想失去手里已有的会怎样，就更珍惜现在的。
- **改不了的坏事**：已经发生的，别反复想"本来可以不这样"。
- **定期复盘**：隔一阵回头看看自己做过的事和当时的感受。
- **处世几条**（第五章 建议和格言）：私事别往外说；别自夸；怒气和恨意别挂在嘴上和脸上；别急着驳倒别人的看法，要说服人就平静地讲；别照抄别人的活法，各人处境不同。
- **能独处**：一个人待得住，就少了很多依赖和麻烦。

适合：对照型、规则型。
例：`叔本华：想过得好，先少受罪` → 别拿健康换钱 / 私事别往外说 / 别跟人争对错 / 已经发生的别反复想……

### 3.《王阳明大传：知行合一的心学智慧》冈田武彦

- **知行合一**：知道却不做，等于不知道。想清楚了就马上做第一小步。
- **念头一起就算数**：坏念头刚冒出来就掐掉，别等它变成行动。
- **事上磨练**：道理要在具体的事上练。没事时心静、一遇事就乱，说明练得还不够。
- **立志如种树**：先扎根（定方向、打基础），别急着要枝叶和果子。
- **龙场四条学规**：立志、勤学、改过、责善——他给学生定的规矩，每条都能拆成今天的动作。
- **对症下药**：心乱就静坐一会儿，犯懒就拿起书看。
- **破心中贼**：管住自己的懒、急、贪、怒，比打败外面的对手更难，也更要紧。
- **身处绝境**：先把自己的心安顿下来，再想办法（龙场悟道）。
- **责善的分寸**：劝朋友要委婉，别当众揭短、让人下不来台。

适合：规则型、步骤型、场景应对型。
例：`王阳明的4条学规，今天照样能用` → 先定一个方向 / 每天学一点 / 错了当天改 / 劝人别当众说……

### 4.《易经的智慧》曾仕强（这一册讲阴阳、命运、乾卦六龙、坤卦）

- **乾卦六条龙＝做事的六个阶段**：潜龙勿用（本事不够先别出头）→ 见龙在田（露头角时找贵人）→ 终日乾乾、夕惕若厉（白天拼、晚上反省）→ 或跃在渊（想跳先试，留好退路）→ 飞龙在天（到了高位多用能人）→ 亢龙有悔（做过头必后悔，见好就收）。
- **坤卦＝当好配角**：厚德载物（多担待）、含章可贞（有本事先藏着，等时机）、括囊（该闭嘴时闭嘴）、履霜坚冰至（看到苗头就提前防）、守本分不抢功。
- **阳极成阴，物极必反**：好事做到头就会转向，凡事留三分余地。
- **曲则全**：绕一点的路往往更安全——说话办事留余地，别一根筋直冲。
- **命与运**：先天条件改不了，后天的选择改得了，把力气花在选择上。

适合：阶段型、规则型、对照型。
例：`乾卦六条龙：职场每一步怎么走`（完整脚本见 examples/script.minimal.json）

### 5.《见识：商业的本质和人生的智慧》吴军

- **拒绝伪工作**：效率很难提高，唯一能控制的是少做不重要的事——先挑出最重要的那件做完。
- **伪工作的样子**：没人需要的"优化升级"、守着旧工具不学新方法、不想清楚就瞎试、做完不检查回头打补丁、把时间耗在不重要的 5%、开没必要的会。每一种都能配一条改法。
- **一万小时的四个坑**：低水平重复、失败了不总结、一个人闷头钻牛角尖、学一样扔一样不积累。
- **讲话做事都要达到目的**：交代完要确认对方真听懂了；做事看结果，不是交差。
- **第一份工作别太在乎工资**：看能不能学到本事、跟到好的人。
- **职场四个误区**：只当饭碗不当职业、把自己当过客不当主人、被人无端指责就乱了阵脚、做事前不打招呼。
- **人生做减法**：选择太多反而难精进；别捡芝麻丢西瓜。
- **对钱的态度**：钱花出去才是你的；钱是挣出来的，不是省出来的；钱可以很快投光（只讲态度，不讲具体投资）。
- **人生是马拉松**：别太在意起跑线，也别玻璃心。

适合：对照型、规则型。
例：`别再假装很忙：伪工作这样改` → 别做没人要的升级 / 先想清楚再动手 / 做完当场检查……

### 6.《智慧做人机巧做事：中国人不可不知的66条为人处世之道》

这本书里不少内容在教人耍心机，**只取自保和把事办好的部分**：
- 防人之心不可无：陌生人的好处先别收。
- 君子不与小人斗：遇到小人，绕开，别纠缠。
- 宁可犯错，不可犯忌：先弄清对方最忌讳什么。
- 多交朋友少树敌：能不得罪的人就别得罪。
- 得理也让三分。
- 凡事做最坏的打算。
- 轻诺必寡信：答应之前先想清楚做不做得到。
- 看透不说透，点到为止。
- 小心名不副实的恭维；可疑的朋友不深交。
- 居安思危，做事留后路；本事不够时少张扬。

**不用**：教人伪装、骗人、投其所好去拿捏人、暗中报复、当墙头草、制造假象。
适合：规则型、场景应对型。
例：`遇到小人，这样处理最省心` → 别当面硬刚 / 重要的事留记录 / 该说的话当着大家说……

### 7.《智慧谋略系列丛书》（帝王统驭 / 历代官场 / 三教九流 / 文人墨客 / 争权夺利 / 中兴名家）

一套历史故事集。用法是**一个故事 → 一条今天能照做的规矩**：
- 陶侃让人把锯木屑、竹头都收起来，后来雪天铺台阶、造船做竹钉全用上了 → 小东西先别扔，分好类收着。
- 子产不拆乡校，让百姓随便议论政事 → 让别人把批评说出来，比堵住嘴有用。
- 刘邦说自己谋略不如张良、治国不如萧何、打仗不如韩信，但能用好他们 → 用人用其长，自己把方向。
- 蔺相如处处避让廉颇 → 为大局让一步，不是怕。
- 邹忌问"我和城北徐公谁美" → 夸你的人不一定说真话，先想想他为什么夸你。
- 齐桓公重用曾经与他为敌的管仲 → 用人别记旧仇。
- 曾国藩扎硬寨、打死仗，营寨先修牢再打仗 → 先把底子筑牢，再往前冲。

画面画**今天的主角在照做**，故事写进口播备注和发布文案，不要画古人、不要画书。
适合：规则型、老话新用型。

### 8.《黄帝内经·养生智慧》曲黎敏

**只讲日常习惯，不讲治病。**
- 养生四件事：养性情、养睡眠、养居处、家里和睦。
- 恬淡虚无：少计较，心静下来，身体跟着好。
- 止怒莫若诗，去忧莫若乐：想发火先读几句诗，发愁了去听听音乐。
- 睡好子午觉：晚上 11 点前睡下，中午小睡一会儿。
- 卧室别太大（室大多阴）；多出门走动，别老闷在屋里。
- 养生不是吃补品，是把作息过规律。
- 《黄帝内经》原文讲春生夏长秋收冬藏：按季节调整作息。

**边界**：不讲病症诊断、穴位治病、偏方、药材用量，不说"能治""根治""排毒"；发布文案里加一句"身体不适请及时就医"。
适合：阶段型（一天、四季）、规则型。
例：`跟着《黄帝内经》过一天：每个时段做什么`

### 9.《经典励志谚语》《经典格言警句》（智慧背囊系列）

中外谚语和名人格言的合集，按人生哲理、励志进取、优秀美德分类。用法是**老话新用**：
一格一句大家耳熟的老话，冒号后面跟一句今天怎么做。
- 量体裁衣：花钱先看收入
- 割鸡焉用牛刀：小事别动用大资源
- 小鸡没孵出来别先数：钱没到手别先花
- 习惯是第二天性：想变先换习惯
- 满招损，谦受益：做成了也别到处说
- 众人拾柴火焰高：大事先拉上帮手
- 种瓜得瓜：想要什么，先去种什么

老话要选一眼能懂的；生僻的古文要么不用，要么后面的做法写得特别直白。
适合：老话新用型。

## 五、边界（踩了就换选题）

- 教人自保、做事、与人相处；**不教人算计、欺骗、整人**。
- 养生只讲作息、饮食、情绪、运动；**不做诊断，不讲治疗，不给药方**。
- 钱只讲习惯和原则；**不荐股，不承诺收益**。
- 不用绝对化的话（"一定""根治""稳赚""100%"）；不碰政治、擦边、封建迷信——易经只讲做事的道理，不算命。
- 不编造名人名言，不虚构书里没有的内容。

## 六、我的账号信息

- 账号定位/领域：【比如：职场成长 / 人际关系 / 自我提升 / 传统文化 / 生活习惯】
- 目标观众：【比如：25-35 岁一二线打工人 / 刚毕业的大学生 / 小城市宝妈】
- 主角设定：【比如：一只穿西装的章鱼 / 我本人（戴圆眼镜的女生）/ 没有固定主角】
- 画风：【比如：复古双格漫画 / 国潮水墨 / 3D黏土】
- 已经发过的选题（避免重复）：【列几个，没有就写"无"】

## 七、你的任务

产出 **12 个**选题，每个都必须通过第二节的 5 条硬标准。

要求：
- 至少 9 个取材自第四节的取材库，并且至少用到 5 本不同的书；
- 12 个里至少覆盖 4 种第三节的结构，不要全是规则型；
- 每个选题必须**当场验证能拆出 10~14 条做法**——在 `beats_preview` 里先写出前 4 格短标题，写不出 4 条具体做法就换选题；
- 标题直接告诉观众看完能学会什么，不卖关子；
- 守住第五节的边界；
- 中文，口语，不要书面语。

## 追加指令（可选，按需发第二轮）

生成完之后，可以接着发这几句让它自查或深挖：

- **自查**：「把这 12 条按'能不能拆出 12 条画得出来、今天就能照做的做法'重新打分，1-10 分，低于 7 分的直接替换掉，只输出替换后的完整 JSON。」
- **深挖一条**：「第 3 条我要做。请把它扩写成完整的 12 个短标题，每句 5~14 字、祈使句、句式统一，并说明每格画面里主角正在做什么。」
- **一本书连更**：「围绕《穷查理宝典》，再给我 6 个不同观点的选题，做成一个系列连更，每条换一种结构。」
- **对标反推**：「我给你一条爆款的封面文案：『【贴上你抄到的标题】』。反推它用的是哪种结构，然后从取材库里找观点，用同样的结构给我 8 个选题。」

## 小抄：能直接用的标题句式

- `照着做就行：X的N个做法`
- `X之前，先做这N件事`
- `别再X了，换成这N个做法`
- `《书名》里最实用的N条，今天就能用`
- `从新手到X，每个阶段该怎么做`
- `遇到X，这样处理最省心`
- `N句老话，句句能照着做`
